## 阅读约定

- `面板服务器`：运行 AnyTLS Panel、Caddy 和 SQLite 的 Ubuntu 服务器。
- `节点服务器`：运行代理服务和可选流量采集器的服务器。
- `专线账号`：面板中的一个上游订阅来源，不等同于系统登录账号或下游用户。
- `用户服务`：一位下游用户的服务期、续费记录、当前专线分配和独立订阅链接。
- `主 Token`：可写入所有账号流量的服务器端密钥，不能分发到节点。
- `账号级 Token`：只允许写入一个账号流量的密钥，适合节点侧采集器。
